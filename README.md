# 🚀 Kaggle Projects Repository

このリポジトリは、制作途中の **Kaggle分析プロジェクト集** です。  
現段階では、下記の3つの分析ワークを公開しています。  
いずれも学習と実践を通じ、**機械学習の理解と応用力の向上**を目的としています。

---

## 📂 フォルダ構成

### 1. **時系列解析_店舗商品需要予測**
- **使用データ**: Kaggle 主催「Store Item Demand Forecasting Challenge」  
- **位置づけ**: 大学の課題として時系列解析の理解を深める目的で取り組みました（大会終了後）。  
- **成果**: **満点を獲得（56人中12人のみ）**  
- **内容**:  
  - **R言語**を用いた季節性・トレンド分析  
  - ARIMAモデルなど統計的手法を中心に実装  
  - 分析結果と考察を PDF にまとめて公開  
- **学んだこと**:  
  Rでの統計モデリングを通じ、**時系列データの構造理解とモデル選択の重要性**を学びました。

---

### 2. **LGBM_交通事故リスク予測**
- **使用データ**: Kaggleコンペ「Predicting Road Accident Risk」  
- **参加状況**: 開催期間中に参加し **1671 / 4082位**  
- **内容**:  
  - LightGBM による事故リスク（分類）モデル  
  - 前処理・EDA・特徴量重要度の可視化  
  - 分析過程を Jupyter Notebook で整理  
- **学んだこと**:  
  特徴量重要度を活用し、**精度と説明性のバランスをとったモデル構築**の考え方を習得しました。

---

### 3. **LGBM_ローン返済予測**
- **使用データ**: Kaggleコンペ「Predicting_Loan_Payback」  
- **参加状況**: 開催期間中に参加し **3037 / 3724位**  
- **内容**:  
  - LightGBM によるローン返済予測（返済=1 / 未返済=0）  
  - EDA から特徴量作成、モデル学習まで Notebook に整理  
  - Pivot を用いて、仮説ベースで特徴量を構築  
  - カテゴリ変数に応じてエンコーディング手法を使い分け、精度向上を確認  
- **学んだこと**:  
  **仮説ドリブンな特徴量設計の重要性**や、カテゴリ変数の扱い方による  
  モデル精度への影響を実務的に理解することができました。
